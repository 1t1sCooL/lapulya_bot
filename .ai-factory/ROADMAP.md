# Project Roadmap

> OSINT Telegram-бот для глубокой разведки по открытым источникам: ФИО, телефон, транспорт, соцсети, документы, юрлица, адреса, онлайн-следы и фотографии.

## Milestones

- [x] **Пробив по ФИО** — поиск по имени/отчеству/фамилии через breach-базы, VK, Telegram и открытые реестры
- [ ] **Глубокий пробив по телефону** — WhatsApp-регистрация, Telegram по номеру, проверка через caller-ID базы
- [x] **Расширенные соцсети** — поиск по Instagram, Twitter/X, Facebook, Одноклассники
- [x] **Поиск по транспорту** — пробив госномера автомобиля через открытые источники (ГИБДД-стиль)
- [x] **Документы физлиц** — поиск по СНИЛС, серии/номеру паспорта, ИНН физлица
- [x] **Юридические лица (ЮЛ/ИП)** — пробив по ИНН, ОГРН, ОГРНИП через ЕГРЮЛ/ЕГРИП (nalog.ru API, dadata)
- [x] **Адреса и недвижимость** — поиск по адресу, объектам недвижимости через Росреестр и ФИАС
- [ ] **Сетевая разведка (Shodan)** — расширенный анализ IP/доменов через Shodan API (уже в requirements)
- [ ] **Распознавание лиц** — идентификация личности по фото через специализированные API (PimEyes и альтернативы)
- [x] **Сводный OSINT-отчёт** — единая команда `/osint` для агрегации всех модулей по одному объекту
- [x] **Базовая инфраструктура бота** — aiogram 3, access control, маршрутизация хендлеров, форматтеры
- [x] **Domain & IP OSINT** — WHOIS, DNS-записи, SSL/субдомены через crt.sh, геолокация IP
- [x] **Email + базы утечек** — HIBP, LeakCheck, DeHashed, IntelX, BreachDirectory
- [x] **Анализ номера телефона** — парсинг через phonenumbers: страна, оператор, часовой пояс
- [x] **Поиск username** — Sherlock-style поиск по 35+ платформам с прогресс-обновлением
- [x] **Соцсети: VK и Telegram** — профили пользователей и групп VK, публичные страницы Telegram
- [x] **Реверс-поиск по фото** — загрузка фото и поиск совпадений через Yandex Images
